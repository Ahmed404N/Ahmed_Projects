# Binmolhy Group Product Catalog

A modern, responsive product catalog website for Binmolhy Group's snacks, tea, and food collections. The site is a showcase-only catalog with external "Buy Now" links to marketplaces (Shopee, Lazada, etc.).

## Pages

- **Home**: Brand banner, featured products, category highlights, new arrivals.
- **Products**: Full catalog with search and category filters.
- **Product Details**: Rich product information, ingredients, and external purchase links.
- **Admin Login & Dashboard**: Local catalog management (add/edit/delete products, upload images, mark featured/new/best sellers).
- **About & Contact**: Optional supporting pages.

## Run locally

```bash
python -m http.server 8000
```

Open `http://localhost:8000/index.html`.
